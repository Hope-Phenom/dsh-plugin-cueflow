# M6 P0-3 – P0-6 从机实测 · 2026-10-28

> 目标机：<test-host> 的真实 DSH desktop profile。所有测试通过 loopback Host API + remote-use 面板完成。
> 注意：DSH 每次重启后 loopback 端口变化（本次 52748 / 63622）；不能写死。

| 测试 | 结果 |

## P0-6 取消

| 测试 | 结果 |
|---|---|
| Shell 长任务取消 | 2s 内 run/node `cancelled`，`ping` 子进程随 abort 结束 |
| Agent 长任务取消 | 800ms 后 cancel；5s 内 run/node `cancelled`（<run-id>） |
| Agent child dispose | 适配器在 abort 时显式 `activation.dispose()` 并与其 result 竞速；单测断言 dispose 调用 |

## 发现的修复

1. **Agent abort 不够**：只传 signal 时 DSH subagent 不会立即结束；adapter 改为 abort 时 dispose + 拒绝，修复后真实 Agent cancel 生效。
2. **workflow selector 陈旧**：加载 run 快照时没有同步 `workflows` 列表，selector 回退到旧项；`ensureWorkflowSummary()` 修复，从机 remount 验证通过。
3. **active run 列表陈旧**：`GET /runs` 只读落盘，running/queued 不在其中；RunManager merge 内存记录修复。
4. **事件轮询**：`node/heartbeat` 不改变状态，只追加日志/事件。
