## 2. P0-2 CSRF

真实 Host 路由（当前 loopback 端口 `49231`）：

| 请求 | 结果 |
|---|---|
| `POST /runs` 无 `X-CueFlow-Request` | ✅ 403 `CSRF_REQUIRED` |
| `POST /runs` 带 header + JSON | ✅ 201，run 创建 |
| `POST /runs/:id/approvals/:id` 带 header + JSON | ✅ 200，批准 |
| 面板自身加载/保存/运行 | ✅ 同源 header 正常 |

## 3. 注意

- 桌面 DSH 重启后 loopback 端口从 `60167` 变为 `49231`；不能写死，需用 `netstat -ano | findstr <DSH PID>` 查。
- 审批 API 的 JSON body 必须用文件/正确转义传给 PowerShell；直接单引号内联会被 PowerShell 去掉引号，得到 `BAD_JSON`。
- 本次只验证 Shell；Command 审批使用同一 executor 路径，待后续真实 Command smoke 补。

## 4. 清理

测试 workflow/run 可在 `$DSH_HOME/storages/dsh-plugin-cueflow/` 清理；不要删除用户自己的 workflow。
